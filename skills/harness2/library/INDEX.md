# Harness² Persistent Experience Library

This directory stores per-domain adopted harnesses and evidence-backed lessons (`<domain>/INDEX.md` and `<domain>/harnesses/<task>/EXPERIENCE.md`) accumulated by Antigravity across tasks.

## Structure
- `<domain>/INDEX.md` — Domain index of adopted harnesses and situational cues.
- `<domain>/harnesses/<task>/harness/` — Full snapshot of the adopted `c1..c8` component tree.
- `<domain>/harnesses/<task>/EXPERIENCE.md` — Edit attribution (`helped` | `hurt` | `no observed effect` | `confounded`) and the transferable lesson (`cue`, `lesson`, `evidence`, `confidence`).
